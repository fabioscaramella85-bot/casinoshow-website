Casino Show self-hosted fonts.

The site previously requested these families from Google Fonts, roman style only:
Playfair Display 500, 600, 700; Montserrat 400, 500, 600, 700;
Source Serif 4 700; Source Sans 3 600, 700. Subsets: latin and latin-ext.

Google answered with variable WOFF2 files from fonts.gstatic.com. Each committed
file is a static instance at the listed weight, containing the glyphs of both
subset files. Outlines at that weight are the instance of the downloaded font.
No italic is included.

next/font/local applies one declaration list to every file in a family, so the
CSS does not repeat unicode-range. Characters outside the two subsets are absent
and fall back, as they did when unicode-range excluded them.

The CSS variables stay --font-playfair, --font-montserrat, --font-social-serif
and --font-social-sans. Next assigns its own font-family name at build time.
The name inside the font file is only the Open Font License name.
